# Symbols for MS Flight Simulator 1.05 (used by tools/fs1dis.py)
#
#   code SEG:OFF name                ; comment
#   var  SEG:OFF name [byte|word|dword|table|text] ; comment
#
# Code is segment 0050 (linear 00500-0685F) and identical at runtime, except 0050:07BD
# (self-patched immediate) and 0050:5C80+ (one-time init code, later reused as data:
# DS:0000 = CS:5C80). Game data segment DS=0618 (stored at 0000:0120 for the ISRs).
# Angles: 16-bit binary, 0x10000 = 360 deg. Sin/cos: Q15. Controls: signed 16-bit, 7FFF = full.
# Evidence: [key] = observed via scripted key presses; [code] = read from the disassembly;
# "?" in a comment = plausible but unconfirmed.
