# 3.11 Gauge updaters

Area file: `src/natives/gauges.c`. No new shared header. No other area's file was touched.

## Natives

All 24 are enabled by default and cycle-exact. Each native adds the emulated cycles the original
takes on the path it ran, using the `cpu8086.c` model. A temporary check (not committed) compared
the native's cycles with the original's on every verified call and found 0 differences across the
campaign.

The gate is `python tools/verify_campaign.py` with all natives (main + these). It prints OK on top of
origin/main (with 3.8, 3.9 and 3.13 merged and the timing fix).

`upd_tach` has no calls because its only entry is the JMP from `rpm_lag`. It was verified separately
with `--native-off rpm_lag`: 3619 calls (forced-input run, before the rebase), 0 mismatches.

**Forced paths.** Paths the campaign never reaches were forced with a temporary, uncommitted patch
in `verify_call`. The patch wrote random values into the inputs before the snapshot: pitch, bank and
roll rate; OBI targets and flags; marker bits; turn rate; airspeed; vertical speed; altitude; magnetos
and switches; panel_mask bits; and `[1E20]` set for an altimeter divide overflow. A run with `--trace`
showed every instruction of 262C–2AA4, 240E–2525, 25D4–2619, 037E, 0327, 1FE0–2075, 207C, 1150, 0742,
1582, 151C–1582 and 1375 executed, and these calls had 0 mismatches.

Two paths could not be verified this way:
- The byte-mask branch of `panel_update_mask` (221F, `[19A5]`). When forced, the original itself runs
  away, so the records at 1A09 are not real. The C code shares `mask_apply` with the verified word
  path.
- 2FF8–300A of `update_time_of_day`.

## How calls out are made

- `draw_indicator`, `draw_needle`, `draw_needle2` and `blit_sprite` go to the 3.10 C helpers
  (`panel.h`).
- Other original code is run on the CPU core with `call_orig` / `jmp_orig`, with the natives
  switched off. This covers:
  - print_str 1225, print_str_dim 122B and print_str_mask 122E
  - 5AD7 and 5AF3, the rectangle clear and restore
  - the redraw routines at the panel record +4
  - clear_view_buffer and fmt_signed_dec

  Each costs exactly what the original costs. The natives are switched off during these calls
  because a nested native under `--verify` would overwrite the outer verification's logs.
- **print_str and 3.9.** The brief asks for 3.9's C print_str. `textdraw.h` exposes only the glyph
  loop (`textdraw_string`), not the entry code, the registers left behind or the cycles. The swap
  needs a full `print_str_mask` body with cycles in `textdraw.h`, or a framework call that runs a
  native's C function without dispatch. It is left as a follow-up.
- `upd_altimeter` falls back to running the original routine when its DIV would overflow (INT 0), as
  3.10 does for the needles.

## Classification of the phase-dispatch routines

| routine | class |
|---|---|
| sub_207C | VSI needle → `upd_vsi` |
| sub_1375 | heading digits → `heading_readout` |
| sub_2290 | radio nav: computes OBI deflection [1A11], TO/FROM [1A14], glide slope [1A13] from position and the station. Left to 3.12. |
| sub_262C / sub_2620 | attitude indicator → `attitude` / `attitude_fast` |
| sub_0742 | altimeter baseline (field elevation), touches altitude → `field_elev_follow` |
| sub_037E | turn needle → `upd_turn` |
| 240E/2419 | OBI display (consumer of 2290's results) → natives here |
| 2EEC | RPM display lag + tachometer → `rpm_lag` |
