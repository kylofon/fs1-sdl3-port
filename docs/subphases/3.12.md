# 3.12 Radio navigation

## Natives

All nine are enabled by default and transliterated with exact per-path cycle accounting (a
temporary check, not committed, compared charged and original cycles on every verified
campaign call: all equal).

`atis_start` gets no calls with all natives on: its only caller, op_com_station, is inside 3.8's
`scenery_interp` native, which calls 4FBF as original code (hooks off). Verified with
`--native-off scenery_interp --native-off draw_scenery` in the two ATIS sessions: 1 call each,
0 mismatches. 3.8 could call it through the hook instead.

Calls to the print_str family (1225 / 122B / 1282) push the return address and single-step the
original (hooks off), charging its measured cycles. Stepping with hooks on would run 3.9's
natives, but under `--verify all` it nests a print_str verify inside the radio native's verify
and corrupts the logs (seen as mismatches at B800:160B). 3.9 exports no callable C print_str; a
`text_call_print_str(pc, ret_ip)` like panel.h's would let radio.c call it directly.

flag_mask is 0 everywhere: every caller follows with CALL, MOV, RET or the int8 epilogue.

**Not bound:** `upd_obi` 13C6 is misnamed: it is the heading-indicator readout (moves [06A0]
towards the magnetic heading view_heading−[0917]−[0915] in steps of 1/16 of the gap when within
±0A00h, prints 3 digits at 079F). It belongs to 3.11's gauge list, so it is left to 3.11.

## The radios

**Tuning.** nav_freq / com_freq are ASCII. `N` selects the integer part (108–117, wraps), `N`
twice within ~0.3 s selects the fraction (steps of .05, 95→00 without carry); `=` / `-` change
it. `C` / `CC` the same for COM (118–135). `V` selects the OBI ([06A4], 0..179 in 2° steps).
Every change calls `nav_tune` / `com_tune` / `obi_readout`.
- `nav_tune` and `com_tune` start with `panel_text_gate` (156D): with panel_mask bit 15 clear
  it pops the return address and returns to the caller's caller, so nothing is tuned.
- BCD: digits 2–3 in the high byte, 5–6 in the low: 109.15 → 0915h ([03FF] NAV, [03F2] COM).
- `nav_tune` falls into `nav_search_start` ([31D5]=0, [31D3]=1), also called every 8th frame.
  The scenery pass then copies the matching station (in its ±500-unit box) to 31D6.
- `com_tune` sets [3628]=1 (no message) and [31DE]=1 (search).

**nav_compute (2290), every 4th frame.** Positions are 16.16 in units of 256 m.
1. dn, de = (pos − station) << 4, high words → 16 m units; stored [1A21] (north), [1A23] (east).
2. Both are scaled up together (×2) while both high bytes are within −10h..10h (keeps precision).
3. `sub_2525`: bearing of (east, north) from north clockwise, **0..437h = 3 units per degree**:
   octant by signs and |e| vs |n|, ratio = smaller·65536/larger (DIV), then the 17-entry
   arctangent table 1AE2 (0..870h = 0..45° in 1/48°) with linear interpolation, >> 4.
   This is the radial the aircraft is on (FROM the station).
4. Minus the magnetic variation ([0917]+[0915], binary angle × 438h >> 16), wrapped to 0..437h.
5. Course: if nav_freq's last digit is '5' (any x.x5 = ILS) the localizer course [1A1F] stored by
   the scenery (consumed: XCHG with 0), else OBI × 6.
6. d = radial − course wrapped to −21Ch..21Bh (±180°).
   - |d| ≤ 0F0h (80°): flag 2; 80°–100°: flag 0 (OFF), deviation 0;
   - > 100°: flag 1, d = ∓(21Ch − |d|) (against the reciprocal).
   Flag in [1A14]. Glyph strings: 0 → 0825 "wx", 1 → 081A "rs", 2 → 081F "tuv" (2 is on the
   radial, i.e. FROM; 1 is TO).
7. Needle target [1A11] = 1Eh − clamp(d, ±1Eh): **full scale ±10°** (the same for VOR and
   localizer; 1Eh = centred, range 0..3Ch).
8. Glide slope, only if the scenery stored [1A1D] this pass (consumed): dist = max(|[1A21]|,
   |[1A23]|) (Chebyshev, 16 m units, from the NAV station); h = [0919]/2 ([0919] = altitude word
   from upd_altimeter). If h ≥ dist: [1A13] = 18h. Else r = h·65536/dist − [1A1D] + 1800h and
   [1A13] = (r < 3000h ? r>>8 : r<0 ? 0 : 30h) >> 1, i.e. 0..18h, 0Ch on the slope, one step per
   200h of r. [1A1D] is the glide path as 8·tan(angle)·65536 (Meigs A58E).
   Quirk: [1A1D] is consumed even when no station is received or NAV is tuned elsewhere, and
   uses the last [1A21]/[1A23]; the scenery stores it whenever you are inside its box.
- A DIV overflow is possible only for offsets of exactly 8000h (far outside any station box);
  the native then runs the original (which takes INT 0) before writing anything.
- There is **no DME**: nothing else reads the station record 31D6.

**obi_check 240E / obi_update 2419.** obi_check (twice per frame) falls into obi_update only if
[1A10] ≠ [1A11]; obi_update runs once per frame. If the needle, flag or glide slope changed:
- restore the OBI face (24F4: 13 line pairs × 5 words at 133Ah from segment [3806] to [03C2]);
- print the flag (24D6);
- move [1A10] one step towards [1A11] and OR the needle (2474: record 1A25+3n = screen offset,
  pattern index (bits 0–2, words at 1B04), line count (bits 3–7));
- move [1A12] towards [1A13] and draw the glide-slope bar (24B9: 2 words 5555h at line n+7Ah).
Always then `marker_lamps` (25D4): shifts [1A17], [1A1B], [1A19] (scenery sets 1 each pass, so
a lamp stays lit only while inside the box) into 3 bits and, on change, prints 082A with glyph
79h (dark) or 7Ah ([1A19] = outer), 7Bh ([1A1B] = middle), 7Ch ([1A17] = inner; no scenery
sets it in 1.05).

**ATIS.** op_com_station (3.8) copies runways/temps to 31E0, sets [3626] = text, [3628] = 0 and
calls `atis_start` (4FBF): temperature [31E4+(season−1)] + [202A] → 367A; wind direction
[2087]·360/65536 → 36E9/36EA; wind speed [2085] → 36F0; Zulu hour clock_hour + [1E24] (mod 24)
→ 3662; ceiling [2071]·866h>>16 → 3709/370A (blank when 0); runway [31E0 + [2087]>>14] → 36A9.
Leading zeros become spaces. `atis_tick` (from int8_timer at the [204F] rate, not in the editor):
scrolls 5 rows of 50h-byte ring buffers (3492/34E2/3532/3582/35D2, rotation [3622]/[3624]) into
segment [3490], and every second step appends the next character (font DS:0000, 5 words). The
text stream (4F7D): 20h–7Fh literal, 80h+k fragment k (pointers 362D), 00 ends: [3628]=1, and
after 4Eh idle ticks the view window ([3802..380A]) is restored. The message shrinks the 3D view
while it runs.

## Coverage sessions (not committed; keys for `fs1 --keys`)

All start `120:A,180:B`. Editor: Esc, Return moves down one field, type, Return; North field 10,
East 11 (value = position + 16384), Altitude 12, Bank 14, Heading 15, Airspeed 16, Throttle 17.
- **VOR 113.90** from the start position: `N`, `=`×3, `N N`, `-`×2; `V`, hold `-` 400 frames
  (OBI through all courses); editor alt 3000, bank 20, airspeed 100, throttle 25000 (circling,
  all radials), then `V` and hold `=`.
- **Meigs ILS 109.15** (course 313): `N`, `-`, `N N`, `=`×3; editor north 16369, east 16496 (outer
  marker), alt 1500 (also 1100), heading 313, airspeed 90, throttle 15000; plus starts at
  (−40, 140) heading 300 alt 900 and (0, 100) heading 330 alt 2000.
- **ATIS**: from the start COM `C`, `=`×4, `C C`, `=`×4 (128.05); and at Meigs (north 16400, east
  16465) COM 121.30 (`C`, `=`×15, `C C`, `=`×9).

Every session: 0 mismatches. One parallel run of the Meigs ATIS session exited abnormally once
and was clean on rerun.
